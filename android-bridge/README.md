# Android 远程连接助手

此独立应用把已配对控制端的中继命令转给手机上的官方 Mika MCP。连接由本人开启，前台通知提供停止按钮；配置由 Android Keystore 加密保存。

2026-10-31 修复：服务运行时保存新配置，现在会结束旧连接并切换到新配置。每次连接捕获自己的配置与代号，避免旧工作线程恢复后继续使用过期配置，或清除新连接的引用。

Redmi Note 14 Pro 真机验收通过：在同一个 Android 进程内切换到临时测试中继，实际收到了轮询；随后恢复公网中继。临时测试用的 ADB 转发已删除。脱敏记录在 `reconfigure-acceptance.json`。iPhone 真机已通过公网中继读取到官方 Mika 的最近任务。

`build.sh` 使用本机 Android SDK 构建并验证 APK 签名，不覆盖官方 Mika 应用。当前不承诺重启后自动恢复官方 Mika 的特权执行进程；首次配对、系统后台限制和重启恢复仍需单独处理。
